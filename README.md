# Anime platform concept lab (unofficial)

A password-protected product-concept prototype exploring how a fan's lifecycle on an anime streaming service could work in 2027–2030.

**Unofficial.** Not affiliated with, endorsed by or authorized by Crunchyroll or Sony. All shows, art, partners, prices of goods and community data are fictional. Playback, payments, imports and partner hand-offs are simulated.

This repository holds only an encrypted, single-file build (`index.html`, encrypted with [StatiCrypt](https://github.com/robinmoisson/staticrypt)). The source is not published here. Ask the author for the password.
